1 · The machine

How a signal is made

Every hour the Flask server downloads nine markets from Yahoo Finance, computes indicators on three timeframes, and squeezes them into a score. The dashed box is new: an offline harness that replays the same function on history and grades it.

2 · Is it machine learning?

A linear model whose weights were chosen by hand

The sentiment score is score = Σ wᵢ · xᵢ, the same shape as logistic regression. The difference is that nobody fitted the weights to data. Move the sliders to see how the engine combines its seven pillars. The weights are the ones in engine.py.

Balanced0.0

Labels: ≥ +50 strong bull · ≥ +15 moderate bull · −15…+15 balanced · ≤ −15 moderate bear · ≤ −50 strong bear. "Bullish %" shown on the dashboard is just (score + 100) / 2.

So the honest description is a rule-based quantitative model. The evaluation adds real ML (logistic regression and gradient-boosted trees) trained on the same inputs, to test whether learning the weights helps.

3 · Indicator lab

What an EMA actually does to price

Last ~60 days of WTI (one point every 4 hours) with an exponential moving average. A short span hugs price and flips direction often. A long span is smoother but late. The engine's "trend" logic is just whether price sits above or below these lines. The strip underneath is the sentiment score at each point: green is bullish, red is bearish.

4 · The trap

Look-ahead bias: how fake 100 % accuracy happens

The replay rebuilds exactly what the dashboard could see at each bar's close and nothing after. If the code accidentally lets the model see the next bar (a single shift(-1) is enough), accuracy jumps. The pipeline includes this "oracle" on purpose, as a test that the scoring code works.

5 · Accuracy explorer

Every model against the same answer key

For each hour, the call (bull / bear) is compared with the actual return over the horizon. Baselines matter. Oil rose in about 51–52 % of windows, so a model that always says "up" already beats 50 % with zero skill.

Horizon in trading hours

p-values come from non-overlapping samples only (every h-th bar). Pesaran–Timmermann tests timing skill after accounting for how often the model says "up" and how often price actually went up. MCC is 0 for random guessing and 1 for perfect.

Confusion matrix · 7-pillar sentiment

Rows = what happened, columns = what was predicted. FLAT = move smaller than 0.25 × ATR × √h. A useful model is dark on the diagonal.

Is "bullish %" a real probability?

If the dashboard says 70 % bullish, price should rise about 70 % of the time. Points on the diagonal mean well calibrated. Bubble size shows the number of hours.

6 · Playbook audit

Claimed win rates against simulated trades

Each setup was traded on real hourly highs and lows. Rules: limit entry within 6 hours, stop and target checked bar by bar, stop assumed first if both are hit in the same bar, $20 round-turn cost, one position at a time. The grey bar is what the dashboard claims. The coloured bar is what happened.

7 · Rules vs learning

Does machine learning beat the hand-tuned weights?

Models were retrained every 250 hours on past data only, with a purge gap so no training label overlaps the test period. All three models are scored on the identical out-of-sample window. The column to watch is "% calls up". A model that mostly says "up" can look significant against 50 % while having no timing skill.

Price forecasts mapped to actual prices

Theil U2 = model error ÷ error of "price stays the same". Below 1.0 beats the random walk. MAPE looks tiny (≈0.4 % at 1h) but means little on its own.

What the logistic model leaned on (4h)

Standardised coefficients. The crack pillar and raw crack point opposite ways because one is a clipped copy of the other (collinearity), so read signs with care.

8 · Envelopes & detectors

Do the statistical bands hold?

VWAP bands are a bit too narrow because oil returns have fat tails. The Value Area describes where volume traded over the last 24 hours. It is not a forecast of where price will be, and the numbers show that.
